# 📈 Indian Stock Analytics Dashboard

A modern stock analytics dashboard built entirely with **Python** using **NiceGUI**. This project provides an interactive interface to explore Indian stock market data, including custom performance tables for NIFTY 50 and SENSEX 30 companies.

---

## 🚀 Features

- 📊 Interactive Dashboard
- 🔍 Search stocks by symbol or company name
- 📈 Performance tables (1 Week, 1 Month, 3 Months, 6 Months)
- 📑 Clickable stock details page
- 📉 Interactive price charts
- 📋 Company information and key statistics
- 🌙 Modern dark theme
- 📱 Responsive design

---

## 🛠️ Technologies Used

- Python
- NiceGUI
- Pandas
- Plotly
- yfinance
- SQLite

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/saikiran-512/indian-stock-analytics-dashboard.git
```

Go into the project folder:

```bash
cd indian-stock-analytics-dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open your browser:

```
http://localhost:8080
```
